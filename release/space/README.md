# 🧬 M.A.I, Modern AI

A 97M parameter base model trained from scratch on English and French with
[Modern LLM](https://github.com/Thibault-GAREL/Modern_LLM). It continues a text,
it does not follow instructions. Write the beginning of a sentence, not a question.

Weights: [Thibault-GAREL/mai-v2](https://huggingface.co/Thibault-GAREL/mai-v2).
